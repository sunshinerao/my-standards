# Reference Registry v1.0

## 1. Programme

### The Earthshot Prize — Primary Visual + Homepage Reference

Official site: https://earthshotprize.org/

Assigned design role:

- Optimistic environmental storytelling.
- Bold, accessible grotesk typography.
- Large documentary media.
- Quiet visual system that allows innovators and stories to dominate.
- Modular/scalable structure.
- Strong relationship between brand motion and forward movement.
- Homepage sequence centered on current story, mission, network, thematic goals and impact.

Brand research:

- Justified Studio: https://www.justified.studio/work/the-earthshot-prize
- Pixeled Eggs case study: https://www.pixeledeggs.com/case-study/the-earthshot-prize-website-design/

Verified design cues used in this system:

- The current rebrand uses GT America as its typographic system.
- Motion is described as fluid but structured, expanding/contracting around local-to-global change.
- The design direction is deliberately clean/quiet so solution stories remain central.
- The website was designed as a scalable modular platform with high visual impact and broad-audience accessibility.

### IDEO.org — Supporting Editorial Reference

Official site: https://www.ideo.org/

Assigned design role:

- Project-led homepage.
- Asymmetric editorial composition.
- “Questions we’re exploring” as a content form.
- Strong impact numbers without turning the site into a dashboard.
- Design work presented through story, not feature icons.

### TED Countdown — Supporting Story + Community Reference

Official site: https://countdown.ted.com/

Assigned design role:

- Storytelling as climate action.
- Video-first content.
- Solutions and community pathways.
- Accessible, culturally current tone.

## 2. Platform

### United Nations — Primary Institutional Visual Reference

Official site: https://www.un.org/

Web guidelines: https://www.un.org/en/webguidelines/

Assigned design role:

- Institutional trust.
- Stable navigation and footer.
- Clear content hierarchy.
- Multilingual scalability.
- Accessibility-first behavior.
- Blue/white/neutral visual discipline.

Verified rules used in this system:

- Consistent navigation across pages.
- Skip links and accessibility support.
- Branding/header/footer consistency.
- Language access as a first-class site behavior.
- Six main navigation items maximum is strongly recommended in UN planning guidance.
- Multimedia is permitted when user control and accessibility are preserved.

### The Rockefeller Foundation — Primary Homepage + Interaction Reference

Official site: https://www.rockefellerfoundation.org/

2025 digital impact report: https://impactreport.rockefellerfoundation.org/

Assigned design role:

- Homepage narrative: institutional proposition → current priorities → results → human stories → recent news.
- High-quality documentary media.
- Large editorial type and data.
- Interactive-report thinking.
- Restrained, high-fidelity motion.
- Polished large-panel navigation behavior as the target interaction quality.

Verified content/experience cues used in this system:

- Current homepage prominently presents “Our Current Big Bets,” “Our Results,” “Stories Behind the Data,” and “Recent News.”
- The Foundation’s interactive impact reporting explicitly combines editorial storytelling, video, motion, illustration, data visualization and clear pathways.
- Earlier impact-report work documents number tickers, interactive maps and section video as purposeful interactive components.
- The Foundation states a WCAG 2.1 AA accessibility commitment.

The exact current menu choreography is treated as a **quality reference**, not as a frame-by-frame copied implementation. This system defines an original mega-menu choreography with the same level of polish and restraint.

## 4. Copying Boundary

Reference sites define principles and quality targets. They do not authorize copying.

Do not reproduce third-party:

- logos
- wordmarks
- photographs
- proprietary illustrations
- source code
- exact page compositions
- exact animations
- copyrighted text
